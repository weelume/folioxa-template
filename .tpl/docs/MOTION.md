# 原站动效清单与实现差异

来源是原站页面 CSS、SSR 变体、首屏动画 JSON；未通过浏览器动态观察确认，因此下列推断不可作为完整还原证明。

1. 导航首屏 y=20，弹簧 stiffness=268 / damping=30，延迟 .1s，三端参数一致。
2. 人像卡 y=50，stiffness=300 / damping=60，delay=.1s；文字卡同参数 delay=.2s。
3. 合作品牌循环 ticker，桌面 gap=60；原站手机首屏延迟 2s、stiffness=210 / damping=70。当前循环 26s 为估计值，手机延迟尚有差异。
4. 标题原站拆词，自定义触发与模糊需动态确认。当前逐词滚动显现，不宣称与原站轨迹完全一致。
5. 项目卡片 hover 图片、服务和流程卡、工具展示、报价按钮、评价卡及案例最新项目横向循环须逐项动态比较。案例相关项目已实现横向循环，三端已实测持续运行及聚焦暂停；与原站的速度、轨迹仍待完整比较。
6. FAQ 展开与收起、移动菜单高度切换、按钮按压已实现；节奏待实机比较。
7. 未确认原站拖拽行为，因此不额外引入拖拽；当前专家卡仅保留悬停反馈。
8. 原始 HTML 未发现 video 标签，暂未发现运行视频；仍需动态检查。
9. 尊重 prefers-reduced-motion，ticker 可 hover/focus 暂停；菜单、FAQ 和三端作品循环已实测；全部原站动态逐项对照仍未完成。
